# Neural Master Pro 2.2

Suite professionale di mastering audio basata su IA. Offre analisi dettagliate, abbinamento con tracce di riferimento, monitoraggio hardware (CPU/GPU) ed esportazione flessibile.

## Caratteristiche Principali
- AI Mastering e Traccia di Riferimento
- Diagnostica profonda: LUFS, True Peak, RMS
- Taglio della traccia temporale ed esportazioni video/audio
- Indicatori hardware: i badge CPU/GPU mostrano i nomi reali dei dispositivi e, se i sensori sono disponibili, le temperature reali (altrimenti «--°C»)

## Installazione (Windows)

1. Scarica ed estrai il repository nella cartella desiderata, ad esempio `C:\Il\Tuo\Percorso\Per\Neural_Master_Pro`.
2. Apri **Windows PowerShell** (Consigliato eseguire come amministratore per sensori hardware precisi).
3. Naviga fino alla cartella: `cd C:\Il\Tuo\Percorso\Per\Neural_Master_Pro`
4. Installa le dipendenze: `npm install`
5. Costruisci l'eseguibile: `npm run build:exe`
6. Il file di configurazione (es. `Neural Master Pro 2.2 Setup 2.2.0.exe`) verrà generato all'interno della cartella `release`.
