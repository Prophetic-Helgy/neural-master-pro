# Neural Master Pro 2.2

Профессиональная программа для мастеринга музыкальных треков (в том числе созданных нейросетями). Позволяет на выходе получать идеальное релизное качество без клипинга с плотным звуком, правильно настроенным и не определяющимся как ИИ-сгенерированный на слух.

## Возможности
- **AI Мастеринг**: Автоматическое считывание аудио и применение оптимальных настроек эквалайзера и компрессии через ИИ.
- **Работа с Референсом**: Подгрузка референс-трека с возможностью прямого переключения и мониторинга для точной подгонки характеристик.
- **Диагностические панели**: Точные значения LUFS, Peak, RMS и фазовая корреляция в реальном времени.
- **Обрезка и Экспорт**: Встроенная система таймлайна с автоматическим и ручным выставлением точек обрезки. Экспорт в WAV и видео-визуализацию.
- **Отображение Аппарата**: Плашки CPU и GPU в заголовке показывают реальные имена устройств и фактические температуры, когда доступны сенсоры (иначе «--°C»).
- **Скорость и Громкость**: Возможность изменения скорости воспроизведения в пределах x3 и точная регулировка громкости.

## Установка (Windows)

1. Скачайте и распакуйте репозиторий в нужную вам папку, например, `C:\Ваш\Путь\К\Neural_Master_Pro`.
2. Откройте **Windows PowerShell** (рекомендуется Запуск от имени Администратора для точной работы сенсоров).
3. Перейдите в папку: `cd C:\Ваш\Путь\К\Neural_Master_Pro`
4. Установите зависимости: `npm install`
5. Соберите исполняемый файл: `npm run build:exe`
6. Установочный файл (например, `Neural Master Pro 2.2 Setup 2.2.0.exe`) появится в папке `release`.
