# Neural Master Pro 2.2

Suite de mastering audio professionnelle pilotée par IA. Comprend des outils d'analyse détaillés, un mode de référence et une fonctionnalité d'exportation complète.

## Fonctionnalités Clés
- Mastering IA et correspondance de référence
- Diagnostics avancés : LUFS, Peak, RMS et Phase
- Découpage et exportation pour flux audio/vidéo
- Indicateurs matériel : les badges CPU/GPU affichent les noms réels des appareils et, si des capteurs sont disponibles, les températures réelles (sinon «--°C»)

## Installation (Windows)

1. Téléchargez et extrayez le dépôt dans le dossier de votre choix, par exemple `C:\Votre\Chemin\Vers\Neural_Master_Pro`.
2. Ouvrez **Windows PowerShell** (Exécuter en tant qu'administrateur est recommandé pour des capteurs matériels précis).
3. Accédez au dossier : `cd C:\Votre\Chemin\Vers\Neural_Master_Pro`
4. Installez les dépendances : `npm install`
5. Compilez l'exécutable : `npm run build:exe`
6. Le fichier d'installation (ex : `Neural Master Pro 2.2 Setup 2.2.0.exe`) sera généré dans le dossier `release`.
