# Neural Master Pro 2.2

مجموعة متطورة لإتقان الصوت بالذكاء الاصطناعي. تتميز بأدوات تحليل قوية ومطابقة المسارات المرجعية، مع إمكانيات التصدير المتقدمة للأنظمة المتعددة.

## الميزات الأساسية
- الإتقان التلقائي عبر الذكاء الاصطناعي
- التحليل الدقيق: LUFS، وPeak، وRMS
- قص وتصدير المسارات (صوت/فيديو)
- مؤشرات العتاد: شارات المعالج/الرسومي تعرض الأسماء الحقيقية للأجهزة والحرارة الفعلية عندما تتوفر المستشعرات (وإلا «--°C»)

## التثبيت (Windows)

1. قم بتنزيل المستودع واستخراجه في المجلد المطلوب، على سبيل المثال `C:\مسارك\إلى\Neural_Master_Pro`.
2. افتح **Windows PowerShell** (يوصى بالتشغيل كمسؤول للحصول على قراءات دقيقة لمستشعرات الأجهزة).
3. انتقل إلى المجلد: `cd C:\مسارك\إلى\Neural_Master_Pro`
4. تثبيت التبعيات: `npm install`
5. بناء الملف التنفيذي: `npm run build:exe`
6. سيتم إنشاء ملف الإعداد (على سبيل المثال، `Neural Master Pro 2.2 Setup 2.2.0.exe`) داخل مجلد `release`.
