# Neural Master Pro 2.2

Suite de masterización de audio profesional impulsada por IA. Cuenta con análisis detallados, pistas de referencia y funcionalidad integral de exportación.

## Características Principales
- Masterización IA y coincidencia de referencias
- Diagnósticos: LUFS, Peak, RMS y Fase
- Recorte y exportación (Audio/Video)
- Indicadores de hardware: las insignias de CPU/GPU muestran los nombres reales de los dispositivos y, cuando hay sensores, las temperaturas reales (en caso contrario, «--°C»)

## Instalación (Windows)

1. Descargue y extraiga el repositorio en la carpeta deseada, por ejemplo, `C:\Tu\Ruta\A\Neural_Master_Pro`.
2. Abra **Windows PowerShell** (Se recomienda ejecutar como administrador para obtener datos precisos de los sensores de hardware).
3. Vaya a la carpeta: `cd C:\Tu\Ruta\A\Neural_Master_Pro`
4. Instale las dependencias: `npm install`
5. Construya el ejecutable: `npm run build:exe`
6. El archivo de instalación (por ejemplo, `Neural Master Pro 2.2 Setup 2.2.0.exe`) se generará dentro de la carpeta `release`.
