# ЧАСТЬ 1: ПОДРОБНЫЙ ОБЗОР ПРОГРАММЫ

## 1. Общее описание

**Neural Master Pro 2.1** — это профессиональный AI-ориентированный аудио-мастеринг инструмент для Windows, предназначенный для преобразования AI-сгенерированных и студийных треков в релиз-готовые мастер-копии. Программа решает ключевую проблему современного музыкального производства: автоматизация мастеринга без потери качества, клиппинга и без "AI-следа" в аудио.

**Автор:** Oleg Abezov  
**Платформа:** Windows (x64)  
**Лицензия:** Бесплатная (Freeware)  
**Версия:** 2.1

|---|---|

## 3. Архитектура DSP-цепочки (FAUST)

Цепочка обработки описана на языке FAUST и компилируется в WebAssembly в реальном времени:

```
┌─────────────────────────────────────────────────────────────┐
│  INPUT (Stereo)                                              │
│    ↓                                                        │
│  1. GAIN STAGE  — общий уровень (-18/+18 dB)                │
│    ↓                                                        │
│  2. EQ SECTION                                              │
│     • Low Shelf (150 Hz)                                    │
│     • Mid Peak EQ (1000 Hz, Q=1.0)                          │
│     • High Shelf (5000 Hz)                                  │
│     • Fundamental Resonance (20-200 Hz, Q=0.125)            │
│     • 10-Band Graphic EQ (31 Hz → 16 kHz)                  │
│    ↓                                                        │
│  3. STEM CROSSOVER (алгоритмическое разделение)             │
│     • Bass Stem:  < 120 Hz (lowpass)                        │
│     • Mid Stem:   120-∞ Hz (lowpass − bass)                │
│     • Side Stem:  (L−R) channel                            │
│     Каждый стем имеет независимую FX-цепочку:               │
│       Distortion → Autotune → Delay → Chorus → Reverb      │
│    ↓                                                        │
│  4. MASTER FX CHAIN                                         │
│     • Distortion (tanh waveshaping)                         │
│     • Autotune (pitch correction)                           │
│     • Delay (feedback, 375ms)                               │
│     • Chorus (modulated delay, 1.5 Hz LFO)                  │
│     • Reverb (Zita-Reverb stereo)                           │
│    ↓                                                        │
│  5. TEXTURE SECTION                                         │
│     • Saturation (tanh distortion)                          │
│     • Exciter (highpass + distortion, 3-10 kHz)             │
│    ↓                                                        │
│  6. DYNAMICS SECTION                                        │
│     • 3-Band Multiband Compressor (Bass/Mid/High)           │
│       Split: <250 Hz | 250-3300 Hz | >3300 Hz              │
│    ↓                                                        │
│  7. SPATIAL SECTION                                         │
│     • Haas Effect (inter-channel delay, ±100 ms)            │
│     • MS Stereo Width Encoder (M/S matrix)                  │
│    ↓                                                        │
│  8. LIMITER                                                 │
│     • Fast Compressor (ratio 20:1, threshold -0.2 dB)       │
│     • Attack: 2ms, Release: 100ms                           │
│    ↓                                                        │
│  OUTPUT (Stereo)                                            │
└─────────────────────────────────────────────────────────────┘
```

### Параметры DSP (45 параметров в реальном времени):
- **Gain, EQ (3 shelf + 10 graphic), Compression, Limiter**
- **Saturation, Exciter (amount + freq)**
- **Haas, Stereo Width, Fundamental Freq**
- **FX: Autotune, Reverb, Distortion, Delay, Chorus** × 4 стема (master, bass, mid, side)

## 4. Функциональные модули

### 4.1 Audio Engine (AudioEngine.ts — 933 строки)
- Загрузка треков и референсов
- Playback с изменяемой скоростью (±3x, без искажения высоты)
- Bypass (A/B сравнение dry/wet)
- Reference toggle (A/B с референсным треком)
- Real-time анализаторы (L/R AnalyserNode, FFT 2048)
- Automation регионов эффектов (15ms polling)
- Экспорт в WAV через OfflineAudioContext
- Анализ буфера: BPM, RMS, LUFS, Crest Factor, корреляция, стерео-ширина

### 4.2 Diagnostic Panel (DiagnosticPanel.tsx)
- Визуализация RMS/Peak/LUFS в реальном времени
- Phase Correlation метр
- Спектральный анализ (6 полос: Sub, Low, LowMid, Mid, HighMid, High)
- Стерео-ширина и корреляция
- Timeline-график уровней по всей длине трека
- Hardware мониторинг (CPU/GPU температура)

### 4.3 Mastering Control (MasteringControl.tsx)
- 45 параметров мастеринга с real-time обновлением
- Группировка по секциям: EQ, Dynamics, Texture, Spatial, FX
- 4 стема FX: Master, Bass, Mid, Side
- Auto-master кнопка (алгоритмический анализ + рекомендации)
- Bypass / Reference toggle

### 4.4 Graphic EQ (GraphicEQ.tsx)
- 10-полосный графический эквалайзер (31 Hz — 16 kHz)
- Визуальные вертикальные слайдеры
- ±12 dB на каждую полосу

### 4.5 Audio Visualizer (AudioVisualizer.tsx)
- Canvas-визуализация формы волны
- Навигация по таймлайну (клик = seek)
- Playback cursor с real-time позиционированием

### 4.6 Metering Bridge (MeteringBridge.tsx)
- Мост между Web Audio API и React UI
- Real-time обновление метрик
- L/R раздельный анализ

### 4.7 AI Mastering Engine (geminiService.ts)
- Алгоритмический анализ Original vs Reference трека
- Автоматическое вычисление:
  - Gain matching (по RMS)
  - Spectral matching (EQ по 6 полосам)
  - Dynamics matching (Crest Factor)
  - Texture matching (Saturation + Exciter)
  - Stereo Width matching
  - Fundamental Frequency tuning

## Технические заметки для съёмки

1. **Запись экрана:** OBS Studio, 1080p60, 50+ Mbps bitrate
2. **Код:** VS Code с темой One Dark Pro, шрифт Fira Code 14pt
3. **Аудио:** Записывайте системный звук отдельно через VB-CABLE для чистого audio track
4. **Треки для демо:** Подготовьте 2 трека — "сырой" AI-трек и популярный референс
5. **Анимации:** Zoom/pan реализуйте в монтаже (After Effects или DaVinci Resolve)
6. **Таблицы:** Создайте графические оверлеи для сравнения — не показывайте текст в программе
